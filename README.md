# הכנה למערכת ניהול עתידית

האתר הנוכחי הוא frontend סטטי. כדי להוסיף מערכת ניהול בהמשך, אפשר להחליף את מערך `products` ב-API ולשמור במסד נתונים את המידע הבא:

- מוצרים: שם, תיאור, מחיר רגיל, מחיר מבצע, זמינות, צבע ותמונות.
- הזמנות: פרטי פריטים, מידה, הדפסה בגב, כמות, אופן קבלה, סכום, שם, טלפון וסטטוס.
- ביקורות: שם, טקסט, דירוג, מזהה הזמנה מאומת וסטטוס אישור.
- הגדרות חנות: מספר וואטסאפ, מחירי משלוח, קוד קופון ומבצע כמותי.

חשוב: בגרסה הנוכחית קוד הקופון נמצא בצד לקוח ולכן אינו סודי באמת למשתמש טכני. כאשר תחובר מערכת ניהול, יש להעביר את אימות הקופון לצד שרת.
